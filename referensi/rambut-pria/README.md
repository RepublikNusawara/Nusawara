# Model Rambut Pria

Contoh model rambut untuk karakter pria (tampak depan & samping lebih baik).

**Cara menambah foto:** buka folder ini di GitHub → **Add file** → **Upload files** → pilih foto → **Commit changes**.

**Nama file = nama gaya** yang akan muncul di pilihan karakter. Pakai huruf kecil dan tanda hubung, contoh: `undercut.jpg, comma-hair.jpg, spike.jpg`.

Format: JPG, PNG, atau WEBP. Satu foto untuk satu gaya.
