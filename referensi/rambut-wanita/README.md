# Model Rambut Wanita

Contoh model rambut untuk karakter wanita.

**Cara menambah foto:** buka folder ini di GitHub → **Add file** → **Upload files** → pilih foto → **Commit changes**.

**Nama file = nama gaya** yang akan muncul di pilihan karakter. Pakai huruf kecil dan tanda hubung, contoh: `bob.jpg, kuncir-kuda.jpg, panjang-lurus.jpg`.

Format: JPG, PNG, atau WEBP. Satu foto untuk satu gaya.
