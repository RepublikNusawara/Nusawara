# Ekspresi Wajah

Contoh ekspresi wajah (mata, alis, mulut) yang diinginkan.

**Cara menambah foto:** buka folder ini di GitHub → **Add file** → **Upload files** → pilih foto → **Commit changes**.

**Nama file = nama gaya** yang akan muncul di pilihan karakter. Pakai huruf kecil dan tanda hubung, contoh: `senyum.jpg, ngantuk.jpg, kaget.jpg, marah.jpg`.

Format: JPG, PNG, atau WEBP. Satu foto untuk satu gaya.
