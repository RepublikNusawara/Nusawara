# Aksesoris

Contoh topi, kacamata, tas, kalung, atau barang yang dibawa.

**Cara menambah foto:** buka folder ini di GitHub → **Add file** → **Upload files** → pilih foto → **Commit changes**.

**Nama file = nama gaya** yang akan muncul di pilihan karakter. Pakai huruf kecil dan tanda hubung, contoh: `topi-bucket.jpg, headphone.jpg`.

Format: JPG, PNG, atau WEBP. Satu foto untuk satu gaya.
