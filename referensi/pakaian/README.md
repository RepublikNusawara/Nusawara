# Pakaian

Contoh baju, jaket, celana, rok, atau sepatu.

**Cara menambah foto:** buka folder ini di GitHub → **Add file** → **Upload files** → pilih foto → **Commit changes**.

**Nama file = nama gaya** yang akan muncul di pilihan karakter. Pakai huruf kecil dan tanda hubung, contoh: `sweater-oversize.jpg, kemeja-flanel.jpg`.

Format: JPG, PNG, atau WEBP. Satu foto untuk satu gaya.
