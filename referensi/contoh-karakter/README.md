# Contoh Karakter Lengkap

Contoh gaya karakter secara utuh (seperti gambar chibi 3D yang sudah dipakai).

**Cara menambah foto:** buka folder ini di GitHub → **Add file** → **Upload files** → pilih foto → **Commit changes**.

**Nama file = nama gaya** yang akan muncul di pilihan karakter. Pakai huruf kecil dan tanda hubung, contoh: `chibi-sweater.jpg`.

Format: JPG, PNG, atau WEBP. Satu foto untuk satu gaya.
